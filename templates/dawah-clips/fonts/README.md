# Arabic paper font

Noto Naskh Arabic variable font, weights 400–700. Retrieved 2026-11-12 from the
[Google Fonts source](https://github.com/google/fonts/tree/main/ofl/notonaskharabic).
Copyright The Noto Project Authors. Distributed under the bundled `OFL.txt`.

`dawah-paper.tsx` loads this local file and waits for it before rendering. No runtime
Google Fonts request is needed. Use weight 600 for paper quotations and labels;
the regular caption track retains its existing Arabic sans-serif stack.
